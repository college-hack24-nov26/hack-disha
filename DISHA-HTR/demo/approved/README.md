# Quick samples — doctor style pack

These PNGs are the **judge / demo quick samples**. Each was verified for an **exact match** on `checkpoints/trocr-heldout-push`.

## Story for judges

1. Feed **alphabet / letter drills** for a clinician (`A B a`, `H I`).
2. Add that clinician’s **personal phrases** (name, greetings).
3. Recognition on matching lines becomes reliable — these chips show that adapted hand.

See `samples_manifest.json` for expected text and stage labels.

Older uncurated demos (if present) live under `archive_old/` and are not shown in the UI.
