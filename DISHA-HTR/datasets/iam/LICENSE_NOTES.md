# IAM licensing notes (DISHA-HTR)

| Item | Detail |
| --- | --- |
| Dataset | IAM Handwriting Database 3.0 |
| Provider | FKI / HEIA-FR (formerly University of Bern) |
| Official page | https://fki.tic.heia-fr.ch/databases/iam-handwriting-database |
| License posture | Free for non-commercial research use |
| Registration | **Required** before downloading forms/lines/words/ascii |
| Bypass | **Not allowed** in this project — scripts require `IAM_USERNAME` / `IAM_PASSWORD` |
| Redistribution | Do not commit IAM images/archives to git |
| Citation | U. Marti and H. Bunke. The IAM-database: an English sentence database for offline handwriting recognition. IJDAR, 2002. |
